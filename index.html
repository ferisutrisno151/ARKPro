Download Aplikasi & APK

Aplikasi ini berbasis web modern (PWA / Progressive Web App). Anda dapat mengakses langsung lewat browser atau mengubahnya menjadi aplikasi Android (.apk) menggunakan layanan pembungkus WebView gratis seperti AppMySite atau PWABuilder.

Cara Install di HP:

1. Buka link web ini di Chrome (Android) atau Safari (iOS).

2. Ketuk menu browser (titik 3 di kanan atas).

3. Pilih "Tambahkan ke Layar Utama" (Add to Home Screen).
